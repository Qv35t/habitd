# habitd

terminal-style habit tracker. local-first. no accounts. no cloud.

> full README coming in Phase 7

## quick start

```bash
git clone https://github.com/Qv35t/habitd
cd habitd
pnpm install
pnpm dev
# open http://localhost:5173
```

## data

all data stored in browser IndexedDB. no cloud. no sync.
